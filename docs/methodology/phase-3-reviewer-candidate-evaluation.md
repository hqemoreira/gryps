## Non-ranking statement

No numerical “fitness score” is used. Judgements are **reasoned assessments** from public evidence. Limitations of the search are stated. Criteria are **not** lowered to force a panel.

## 1. Evaluation dimensions

| Dimension | What is asked |
| --- | --- |
| Technical expertise | Public work matching Profiles A/B/C |
| Direct relevance to GRYPS | Ability to criticise catalog-as-path, composite Signature, open D-items |

| --- | --- | --- |
| **Pan + Rushby** | A (+partial B) + C | Deep civil-style interdependency theory thinner — still adequate if Pan presses landing/PoP sharing |

| **Three: Pan + Dueñas-Osorio + Rushby** | A+B+C | Needs third line on permission template; higher coordination cost |

**Recommendation:** Aim for **Pan + Rushby** as first complementary pair; if Pan declines COI/availability, try **Praks + Rushby**. If Rushby declines, **Pan + Dueñas-Osorio** with an explicit ask that Dueñas-Osorio also comment on whether the composite is mathematically meaningful.

**Do not** appoint two Profile A people alone. **Do not** appoint Profile C alone (misses satellite architecture challenge).

---

## 5. Limitations of this evaluation

- Public web search only; no CV interviews  
- Publication volume ≠ willingness to criticise  
- Seniority may reduce availability  
- Shortlist size is **not** maximised; weaker fits were omitted  
- No candidate is “approved” — only “merits further consideration”  

---

## 6. What must be confirmed before invitation (every candidate)

1. Written COI disclosure (operators, insurers, competing scores, prior GRYPS work)  
2. Employer permission for unpaid private technical criticism  
3. Acceptance that valid outcomes include rejecting the Signature approach  
4. Acceptance of REVIEW-02 scope limits (no terrain, no app, no confidential P5)  
5. Contact channel from their institutional page (re-verified)  
6. Permission template naming + holder signature ready
