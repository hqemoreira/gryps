# Product brief — GRYPS

## Name

GRYPS

## One-liner

Non-commercial research prototype: Nordic / Arctic site profile → deterministic **Resilience Signature** (score, grade, risks, ranked connectivity options).

## Audience

Hiring evaluators and OT / satellite connectivity literacy learners — not paying customers.

## Job to be done

On the Advisor (`/#advisor`): enter coordinates + operational profile → generate a Signature in about a minute → read score/grade/top risk/ranked backups.

## Surface types

- Marketing / landing: yes (hero + orientation)
- App screens: Advisor console, Signature results, Research Library, map

## Constraints

- Stack: Next.js, Neon, MapLibre, optional Mistral
- Brand: polar / ops console — dark surfaces, Space Grotesk + JetBrains Mono, ice-blue accents
- Non-goals: customer deployments, SLAs, live RF monitoring, procurement advice, SaaS billing
- Commercial status: non-commercial learning / hiring proof

## Honesty

Never invent: live RF measurements, SLA %, customer logos, compliance certifications, procurement recommendations. Traficom / catalog refs are context only — not blended into the 0–100 score unless documented.

## Success look

Advisor first job is obvious; Model v0.4 layers visible on the teaser; same inputs reproduce the same Signature; copy stays research-prototype.
