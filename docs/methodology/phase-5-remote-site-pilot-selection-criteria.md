# Phase 5 — Remote-site pilot selection criteria

**Document version:** `gryps-remote-site-pilot-selection-criteria-v0`  
**Task:** ENG-02 (preparation only)  
**Recorded:** 2026-11-26  
**Status:** Transparent selection framework. **No numerical suitability score.** No site selected or claimed willing.

## Purpose

Identify what would make a **first research site** informative for GRYPS dependency and resilience research — not what would produce a high Signature.

A suitable pilot does **not** need multiple satellite providers. A site with one connection and an identifiable dependency set may teach more than a dual-brand marketing story.

---

## 1. Criteria

### Essential (must be true, or pilot stops)

| ID | Criterion | Rationale |
| --- | --- | --- |
| E1 | **Voluntary participation** with named organisational approval | No informal “we’ll just look around” |
| E2 | **Knowledgeable technical contact** (ops / OT / network / automation) available for discovery | Senior exec alone is insufficient |
| E3 | **Industrial relevance** to at least one priority sector | Mining preferred for first pilot; others allowed if stronger access |
| E4 | **Operational dependence on connectivity** is discussable (outage consequences exist) | Otherwise research question is empty |
| E5 | **Non-sensitive information pathway** exists (what can be shared without compromising security) | Else stuck at public news forever |
| E6 | **Permission & confidentiality** terms agreed before any restricted detail | Align with restricted-handling + legal review as needed |
| E7 | **No requirement** that GRYPS certify, score or endorse the site | Protects both parties |
| E8 | **Separation** from Phase 3 independent reviewer role for the same person/org without dual-mandate disclosure | Avoid conflicted “validation” |

### Desirable (strengthen research value; not mandatory)

| ID | Criterion | Rationale |
| --- | --- | --- |
| D1 | Geographical remoteness (northern / Arctic / offshore / sparse coverage) | Stresses coverage and backup design |
| D2 | Mix of connectivity technologies (even if only one “production” path) | Surfaces shared vs diverse infrastructure |
| D3 | Tele-remote or autonomous equipment with documented fail-safe on link loss | Makes dependency concrete |
| D4 | Feasibility of confirming at least one infrastructure dependency class (power, gateway, backhaul, control) | Moves beyond interview belief |
| D5 | Potential for **future** operational measurements under separate explicit consent | Enables later maturity ladder — not required for first pilot |
| D6 | Alignment with Lapland / Nordic envelope for comparison with P5-S2 **public** claims (without extending v0 pack) | Methodological continuity |
| D7 | Prior R&D / testbed culture (e.g. Callio) | Lower barrier to honest “unknowns” |
| D8 | Willingness to state what must remain UNKNOWN | Matches GRYPS evidence ethics |

### Explicit non-criteria

| Not a selection driver | Why |
| --- | --- |
| High expected GRYPS score | Research value ≠ marketing score |
| Famous brand alone | Fame ≠ access or dependency clarity |
| Multiple satellite brands on a slide | Diversity claims need independence evidence |
| Provider willingness to “confirm independence” | Provider confirmation ≠ independent corroboration |
| Fit for public homepage demo | Pilot is research, not product content |

---

## 2. How to apply (qualitative)

For each candidate site or organisation:

1. Mark **E1–E8** as met / unmet / unknown.  
2. Any **unmet essential** → not eligible until resolved.  
3. List which **D** criteria are met as research strengths.  
4. Record barriers (security, legal, capacity, COI).  
5. Prefer the candidate with strongest **learning** about dependencies and unknowns — not the “best connected” site.

No weighted points. No implied precision ranking number.

---

## 3. First-pilot preference (planning only)

| Preference | Explanation |
| --- | --- |
| **Research/test environment before production pit** | Easier voluntary scope; fewer OT disclosure risks |
| **Mining sector first** | Strongest public Nordic evidence of tele-remote dependence |
| **Callio FutureMINE-type context** as discovery entry | Meets many desirable criteria without claiming production dual-path validation |
| Production mines (Kevitsa, Kittilä) | Excellent **later** pilots if essentials clear — higher confidentiality bar |

This preference is **not** a selection. Selection requires E1–E8 after real conversations and approvals.

---

## 4. Relation to P5-S2

- P5-S2 Nordic Lapland dual-path pack remains **immutable v0**.  
- A pilot site must **not** be treated as filling P5-S2 unknowns by interview alone.  
- If future evidence is accepted, follow P5-S4/S5 and consider a **separate** pack version — never silently edit v0.  
- Pilot success ≠ “Lapland dual-path validated.”

---

## 5. What a first pilot may and may not conclude

| May | Must not |
| --- | --- |
| Document stated operational requirements and unknowns | Claim measured resilience of the site |
| Record which dependency questions operators cannot answer | Close D-01–D-13 or certify Model v0.4 |
| Motivate a gated evidence request | Publish identifiable site detail without permission |
| Inform methodology limits | Imply GRYPS is operationally proven |
